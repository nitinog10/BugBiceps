# BugBiceps — Engineering Digital Systems That Scale

> **BugBiceps** is a digital engineering studio delivering premium Web Platforms, Mobile Applications, AI Systems, Automation Pipelines, and 3D Visualizations.

For full agency documentation, architecture, design system tokens, and service breakdowns, see [info.md](./info.md).

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack
- **Frontend**: React 18, Vite 6, Tailwind CSS
- **Animations**: GSAP (ScrollTrigger), Lenis Smooth Scroll
- **Design System**: Sora, Inter, JetBrains Mono, Custom Glassmorphism
